# מרדף הבלונים: שלב 0 (אב-טיפוס)

כניסה: אזור ההורים ("ניסוי: מרדף הבלונים"), או `/?runner` בכתובת (פותח את הניסוי ומנקה את הכתובת ל-`#/runner`).

- `src/games/runner/engine.ts`: חוקי הריצה בלי מסך (כביש, מכשולים, כוכבים, שערים, שובי כמרחק, סיום). `engine.test.ts` בודק אותם.
- `render.ts`: Canvas 2D בפרספקטיבה מדומה, ספרייטים שנוצרים פעם אחת. `cat.ts`: החתול המוכן של הסדנה מבט מאחור (בלי פנים) ומקדימה (בחגיגה), נוצר פעם אחת.
- `index.ts`: מסכים, מגע (החלקה ימינה/שמאלה = מסלול, הקשה או החלקה למעלה = קפיצה), פאנל ⚙️ וכפתור "העתק ערכים". הרזולוציה יורדת לבד בטלפון איטי (1.25x ואז 1x).
- שערי החשבון: `createGenerator().next(activeLevel(), enabledTypes)` ו-`recordAnswer` של המנוע המסתגל. תרגיל שגוי חוזר בשער הבא (במקום אחר), ואחרי שתי טעויות התשובה הנכונה מאירה מרחוק.
- `scripts/e2e-runner/`: בדיקות דפדפן (`PORT=5330 node scripts/e2e-runner/touch.cjs [throttle]`, `full.cjs <dir> good|idle|wrong|decent [video]`, `fps2.cjs <throttle> <dpr>`) מול `npx vite --port 5330`.

לא בשלב 0: ציורים, הקלטות, בחירת דמות מהמדף, קושי מסתגל בין ריצות, שער בכניסה (הכניסה מאזור ההורים), אי בלובי.
